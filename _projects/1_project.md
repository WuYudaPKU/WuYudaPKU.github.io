This is a placeholder project page — replace it with your own research project, course project, or competition entry.

To add a project, create a new file in `_projects/` following this format:

- `title`: project name displayed on the portfolio page
- `description`: one-line description shown on the project card
- `img`: thumbnail shown on the portfolio page (put the image in `assets/img/`)
- `importance`: controls the ordering of project cards
- `category`: groups projects into tabs on the portfolio page

The body of this file becomes the project's detail page, where you can describe the background, methods, and results, and include images, code, math, and citations.
